# subtext-es — Traducción al Español para Sublime Text 4

Paquete de traducción al español para los menús principales, menús contextuales y paleta de comandos de **Sublime Text 4**.

## Qué traduce
- Menú superior completo (*Archivo, Edición, Selección, Buscar, Ver, Ir a, Herramientas, Proyecto, Preferencias, Ayuda*).
- Menús contextuales de editor, pestañas, barra lateral, consola y resultados de búsqueda.
- Paleta de comandos (`Ctrl+Shift+P`).

> **Nota:** Algunos textos internos compilados en el ejecutable de Sublime Text (como `Line 1, Column 1` o `Tab Size: 4` en la barra de estado) no pueden traducirse mediante paquetes.

## Instalación (Windows)
1. Haz doble clic en **`install.bat`** (o ejecuta `.\install.ps1` en PowerShell).
2. Reinicia Sublime Text.

## Desinstalación (volver a inglés)
Ejecuta:
```powershell
.\uninstall.ps1
```
y reinicia Sublime Text.
